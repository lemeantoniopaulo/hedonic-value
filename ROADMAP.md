# Roadmap
## M0: Package foundation
R package skeleton, OLS reference model, explanatory decomposition, confidence and prediction intervals, preliminary normative checks.
## M1: Statistical validity
Document and test model assumptions; VIF, leverage, heteroskedasticity, influence and robust standard errors.
## M2: Model selection
Variable screening, nested cross-validation, AICc/BIC, blocked temporal and spatial validation. Post-selection inference caveats.
## M3: Explainable extensions
GLS/WLS, robust regression, GAM and quantile regression; explicit model-family-specific uncertainty semantics.
## M4: Spatial econometrics
SAR/SEM/SDM and residual spatial diagnostics, with spatial leakage prevention.
## M5: Bayesian inference
Posterior inference, credible intervals, posterior predictive distributions and diagnostics.
## M6: Normative evidence
Versioned NBR 14653 rules, separate precision/fundamentation checks, non-automatic compliance conclusions.
## M7: AVM institutional readiness
CAIXA tender requirements matrix, benchmark validation, audit trails, reproducible reports.
## Release gate
No compliance claim without independently reviewed normative requirements, test fixtures and technical sign-off.
