# hedonic-value

Auditable hedonic valuation of Brazilian urban real estate.

An R package with an evolving RcppArmadillo numerical core. Initial development focuses on interpretable statistical models, uncertainty quantification, model diagnostics, and evidence-based normative checks.

**Status:** early development. No ABNT NBR 14653 or CAIXA compliance certification is claimed.

## Planned modules

- Classical OLS regression and diagnostic tests
- Confidence and prediction intervals
- Variable selection and out-of-sample model comparison
- Spatial econometrics and quantile regression
- Bayesian credible intervals
- Traceable normative assessment and reporting

See the source package starter archive supplied in the project conversation for the full initial prototype.
